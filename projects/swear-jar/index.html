Swear Jar

A swear jar for my AI habit. It’s a tiny pixel dashboard of where my credits go while I build Vox2, my lightweight desktop translator: day by day, by focus area, and against its roadmap.

make your own, free see mine, live download github
Why

where is the effort actually going?

I build Vox2, my lightweight desktop translator, mostly by working with Claude. A product has a lot of sides (the interface, bug fixes, the Mac version, releases, the meaning check), and with an AI partner it’s easy to pour effort into whatever feels most interesting that day.

I wanted the work to follow the roadmap, with effort going where the value is. Swear Jar sorts each request into a focus area, prices it, and puts the totals next to the roadmap’s priorities, so drift shows up early.

The sorting is a rough guess, but it already paid off. It showed the meaning check was taking about half the roadmap effort while holding about a third of its value, and that everyday features were falling behind.

Private

private by design

Everything is read on your own computer. If you choose to publish, only totals per day and focus area go up; never your prompts or what Claude wrote.

Yours

make your own

Swear Jar is free and open source. If you build with Claude Code, it can watch your project too: it starts with general focus areas (features, bugs, tests, docs…) that you can rename, and a roadmap is optional.

  1. Download it. Grab swear-jar.zip and unzip it. You’ll get a swear-jar folder (in Downloads, unless you move it). You need Python 3.9 or newer; nothing else to install.
  2. Open a terminal. On a Mac, press command + space, type Terminal and press Return. On Windows, open PowerShell from the Start menu.
  3. Run setup from that folder. Type these two lines, pressing Return after each (on Windows, python instead of python3):
    cd ~/Downloads/swear-jar
    python3 swearjar.py setup
  4. Answer a few questions. Which project to track, a name, and two optional extras: a roadmap to compare against and a GitHub repo to publish to. Press Return to take the suggestion in [brackets].
  5. Open your dashboard at localhost:8642 in your browser.
